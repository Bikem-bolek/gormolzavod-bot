# Гормолзавод бонус бағдарламасы

Python 3.12, aiogram 3 және SQLite қолданатын Telegram боты. Бот мәзір арқылы басқарылады. Telegram-да жаңа ботты ашу үшін Telegram-ның жүйелік `/start` іске қосу әрекеті қажет; қолданушыға арналған басқа пәрмендер жоқ.

## Функциялар

- Қазақша Reply Keyboard басты мәзірі.
- Клиентті тіркеу және Telegram ID сақтау.
- Әкімші тағайындаған ұпайы бар бір реттік код жасау және енгізу.
- Ұпай балансын қарау.
- Сыйлық таңдау, балансты тексеру, ұпайды шегеру және өтінімді базаға жазу.
- Клиенттер саны, берілген ұпай және өтінімдер туралы әкімші статистикасы.
- QR арқылы ботқа өтуге арналған сілтемелерді Telegram қолдайды; QR-кодта боттың `t.me` сілтемесін пайдаланыңыз.

## Орнату

1. Python 3.12 орнатыңыз.
2. Жоба бумасында виртуалды орта жасаңыз: `py -3.12 -m venv .venv`.
3. PowerShell-де іске қосыңыз: `.\\.venv\\Scripts\\Activate.ps1`.
4. Тәуелділіктерді орнатыңыз: `python -m pip install -r requirements.txt`.
5. `.env.example` файлын `.env` деп көшіріп, BotFather берген токен мен әкімші Telegram ID мәндерін жазыңыз.
6. Ботты іске қосыңыз: `python bot.py`.

`.env` үлгісі:

```dotenv
BOT_TOKEN=BotFather_токені
ADMIN_IDS=123456789,987654321
DATABASE_PATH=data/bonus_bot.sqlite3
LOG_LEVEL=INFO
```

SQLite базасы мен оның бумасы бірінші іске қосылғанда автоматты түрде жасалады. `.env` файлын жарияламаңыз.

## Әкімші мәзірі

`ADMIN_IDS` ішінде көрсетілген қолданушыға ғана мына Reply Keyboard батырмалары көрінеді: код жасау, пайдаланушылар санын қарау, ұпай статистикасы және сыйлық өтінімдері. Код жасау үшін ұпай мөлшерін жіберіңіз; бот бірегей бір реттік кодты береді.

## Сыйлықтар
